## Cảnh báo và giới hạn

Build Android có cảnh báo Java native access và plugin `flutter_tts` dùng Kotlin Gradle Plugin. APK vẫn build thành công; đây không phải test failure.

Web build có cảnh báo Wasm dry run từ JS interop trong `flutter_tts-4.2.5`. Bản JavaScript build thành công; không xác nhận khả năng chạy Wasm.

Không sửa source ứng dụng, migration, policy hay cấu hình backend. Chỉ bổ sung báo cáo này; các thay đổi có sẵn được giữ nguyên. Không có tài khoản Auth mới hoặc dữ liệu học mới được tạo trên backend trong lượt chạy local.
